Canvases

How it works. A canvas is a session. Each node is one answer: a picture or words, cc's choice. Dive into a node and you are in a side quest with its own canvas and the whole conversation behind it. The parent never changes; the node becomes a portal. Where you put things is saved, and what you delete tells cc what you don't want more of. An answer is a short list of changes to the canvas, not only a new node: add, change, remove, link, unlink. Every answer is one Undo.
